# 📱 Trigonometría — UAN

[![Norma](https://img.shields.io/badge/Norma-NTE--UAN--APK--001%20v1.3-blue?style=for-the-badge)](https://github.com/PabloeCancino/uan-apk-plantilla-arquetipo)

Aplicación educativa e interactiva para el estudio de la **Trigonometría** (funciones trigonométricas, identidades, triángulo rectángulo y razones en el círculo unitario), desarrollada bajo la norma **NTE-UAN-APK-001 v1.3** de la **Universidad Autónoma de Nayarit**.

---

## 🎯 Características
- 📐 Identidades trigonométricas, ley de senos y cosenos.
- 📐 Notación matemática precisa con KaTeX.
- 🧪 Quizzes interactivos con explicaciones estructuradas.
- ♿ Escala de tipografía configurable (7 niveles).
- 📶 Funcionamiento 100% offline.

---

## 🛠️ Desarrollo Local
```bash
git clone https://github.com/PabloeCancino/uan-apk-trigonometria.git
cd uan-apk-trigonometria
npm install
npm run dev
```
